# Contributing to Portfolio Project

Thank you for your interest in contributing to my portfolio project! Here are some guidelines to help you get started.

## How to Contribute

### Reporting Issues
- Check if the issue already exists
- Provide a clear description of the problem
- Include steps to reproduce (if applicable)
- Share your environment details (OS, browser, Python version)

### Submitting Pull Requests
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes with clear commit messages
4. Push to your fork: `git push origin feature/your-feature-name`
5. Open a pull request with a detailed description

### Code Guidelines
- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused
- Write docstrings for all functions

### Commit Messages
- Use clear, descriptive messages
- Start with a verb: "Add", "Fix", "Update", "Remove"
- Example: "Add responsive navigation component"

## Development Setup

1. Clone your fork
2. Create a virtual environment
3. Install requirements: `pip install -r requirements.txt`
4. Make your changes
5. Test your changes
6. Submit a PR

Thank you for contributing!
