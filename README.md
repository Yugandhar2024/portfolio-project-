# Yugandhar Portfolio

A personal portfolio website built to showcase skills, projects, and professional background in a clean and responsive design.

## Overview

This portfolio is a lightweight static website created with HTML, CSS, and JavaScript. It is designed to be easy to customize, easy to deploy, and suitable for personal branding or project showcases.

## Features

- Responsive single-page portfolio layout
- About section
- Skills and experience section
- Project showcase
- Contact details and social links
- Clean, minimal design

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Yugandhar2024/portfolio-project-.git
   cd portfolio-project-
   ```
2. Open `index.html` in a browser.

Optional local preview:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Customization

Edit the content in `index.html` and the styling in `css/styles.css` to update:

- Name and title
- About text
- Skills
- Projects
- Contact links
- Color palette and layout
